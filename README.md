# דשבורד נוכחות

דשבורד לניתוח נוכחות חודשית של עובדים מתוך קובץ אקסל.

**לאתר: https://einav-yehezkely.github.io/attendance-dashboard/**

## מה רואים בדשבורד

- סיכום חודשי ובחירת תקופה
- כמה עובדים הגיעו בכל יום, ופילוח לפי יום בשבוע
- מפת נוכחות לפי עובד ויום
- שעות לפי שבוע ויום טיפוסי לכל עובד (שעות כניסה ויציאה)
- טבלת עובדים שאפשר למיין, ובדיקת נתונים לאיתור חריגים

## איזה קובץ אפשר להעלות

- כל שבוע הוא בלוק: שורת תאריכים (למשל `א' 28.06.26`), מתחתיה שורת "כניסה / יציאה", ואחריה שורה לכל עובד.
- שמות העובדים נמצאים בעמודה שלפני התאריך הראשון, בדרך כלל עמודה A.
- השעות בפורמט שעה של אקסל, או כטקסט כמו `08:05`.
- יום סגור מסומן בתא ממוזג עם טקסט על פני כל העובדים, למשל "צום תשעה באב".
- אם בקובץ יש כמה גיליונות, כולם נקראים.

## פרטיות

הקובץ נקרא רק בדפדפן ולא נשלח לשום מקום. הנתונים נשמרים ב-localStorage של הדפדפן כדי שיופיעו שוב בביקור הבא, ואפשר למחוק אותם בכפתור סגירת הקובץ.

## מבנה

האתר הוא קובץ אחד, [index.html](index.html), בלי שלב build. כל push ל-`main` מעדכן את GitHub Pages אוטומטית.
